Talents Check

Each raider's current talents (Raider.io) compared with what the top Warcraft Logs players of their spec took on each boss. The % is how many of the core talents (taken by 70%+ of the top 15 US players) the raider has; situational picks like utility or defensives that only some top players take never count against anyone. Missing = taken by 85%+ of them, Rarely taken = 10% or fewer.
To copy a top build: click a boss button below (or a boss column in the table), then find your spec and click Copy build to get an in-game import string.

Great Vault

This week's vault for the raid team (same rules as in game: Raid = different bosses killed since the reset, Mythic+ = keys this week, World = delves), plus season activity so you can see who plays outside of raid nights. Raid kills, keys and delves update with each refresh.

Requests

Ask to add a secondary main (a character you'd raid on: shows as a raid offspec on the roster), an alt (tracked for Great Vault and activity), or to swap to a new main. An officer approves it, then it shows up on the roster.
